# Redivo Homebrew Tap

Install **Redivo Code** on macOS (Apple Silicon & Intel):

```bash
brew install --cask indie-bratya/tap/redivo-code
```

Alternative zero-quarantine one-line installer:

```bash
curl -fsSL https://code.redivo.ru/install.sh | sh
```

Portal & access: [https://code.redivo.ru](https://code.redivo.ru)
